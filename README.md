### 🎮 遊戲規則
這是一款**回合制對戰遊戲**，核心機制如下：
1. **職業選擇：** 玩家進入遊戲後可選擇不同的職業（如：戰士、法師）。
2. **戰鬥系統：** 採用回合制，與敵人交替行動。
3. **戰鬥指令：** 提供多樣化的攻擊指令（重擊、必殺、防禦）。
4. **獲勝條件：** 透過策略運用指令，擊倒敵人即獲得勝利。

### 🛠 程式介紹
本程式採用 C++ 物件導向 (OOP) 設計，重點在於類別繼承與模組化開發：

封裝：將戰鬥邏輯與角色數值拆分，避免代碼冗長。

多檔案連結：透過 Character.h 定義介面，並在 .cpp 實現邏輯。

檔案結構說明：

main.cpp：遊戲主流程控制。

Character.h/.cpp：基底角色類別定義與邏輯。

Jobs.h：各職業衍生類別的數值初始化。

UI.h：戰鬥畫面渲染與框框顯示。
